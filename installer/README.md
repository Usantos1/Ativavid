# ATIVAVID

App Windows para editar vídeo com IA: arraste o arquivo → 1 clique → `final.mp4`.

## Baixar e instalar

1. Abra a [release mais recente](https://github.com/Usantos1/Ativavid/releases/latest)
2. Baixe **[Instalar.ATIVAVID.2.50.exe](https://github.com/Usantos1/Ativavid/releases/download/v2.50/Instalar.ATIVAVID.2.50.exe)**
3. Execute o instalador (pede admin uma vez)
4. Destino padrão: `C:\Program Files\ATIVAVID`
5. Abra pelo atalho **ATIVAVID** (sem janela CMD)

## Primeiro uso

1. **Chaves & IA** — cole a `GROQ_API_KEY` (e outras se precisar)
2. **Estilos** — defina `@marca` no end card
3. **Licença** — ative a chave se o app pedir
4. Arraste vídeos verticais **9:16**

Projetos ficam em `%USERPROFILE%\ATIVAVID\Projetos\`

Configurações (chaves, Supabase, sessões) ficam em `%USERPROFILE%\ATIVAVID\` e **não são apagadas** ao atualizar o app.
